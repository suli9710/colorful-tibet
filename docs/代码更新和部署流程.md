# 代码更新和部署流程

## 📝 完整流程

### 步骤 1：在本地提交代码修改

```bash
# 在本地项目目录（Windows）
cd C:\Users\Suli\Desktop\colorful-tibet

# 查看修改的文件
git status

# 添加修改的文件
git add backend/src/main/java/com/tibet/tourism/DataSeeder.java
git add frontend/package.json
git add frontend/nginx.conf
git add docker-compose.yml

# 提交修改
git commit -m "fix: 修复数据库外键约束错误和前端构建问题"

# 推送到 GitHub
git push origin main
```

### 步骤 2：在服务器上拉取更新

```bash
# 在服务器上
cd /opt/colorful-tibet

# 拉取最新代码
git pull

# 验证文件已更新
git log -1
git diff HEAD~1 backend/src/main/java/com/tibet/tourism/DataSeeder.java
```

### 步骤 3：清理并重新构建

```bash
# 停止服务
docker compose down

# 清理数据库文件（解决外键约束问题）
sudo rm -f data/tibet_tourism.mv.db data/tibet_tourism.trace.db

# 重新构建后端（应用代码修复）
docker compose build backend

# 重新构建前端（应用 nginx 配置更新）
docker compose build frontend

# 启动服务
docker compose up -d

# 等待服务启动
sleep 30

# 查看日志
docker compose logs -f backend
```

## 🚀 快速部署命令

### 本地（Windows）

```bash
cd C:\Users\Suli\Desktop\colorful-tibet

# 提交所有修改
git add .
git commit -m "fix: 修复数据库外键约束错误、前端构建问题和nginx配置"
git push origin main
```

### 服务器（Linux）

```bash
cd /opt/colorful-tibet

# 拉取更新
git pull

# 停止服务并清理
docker compose down
sudo rm -f data/tibet_tourism.mv.db data/tibet_tourism.trace.db

# 重新构建
docker compose build

# 启动服务
docker compose up -d

# 等待启动
sleep 30

# 测试
curl http://localhost:8080/api/spots
```

## ⚠️ 注意事项

1. **提交前检查**：确保所有修改都是正确的
2. **测试本地**：如果可能，先在本地测试
3. **备份数据**：如果服务器有重要数据，先备份
4. **逐步部署**：先更新代码，再重新构建，最后重启服务
