牦牦 Yakmo 桌宠 Windows 便携包

使用方式：
1. 双击 YakmoDesktopPet.exe。
2. 牦牦会作为透明悬浮桌宠出现在桌面右下角。
3. 左键拖拽移动，双击挥手，右键打开菜单。
4. 按 Esc 或右键菜单“退出”关闭。

功能：
- 原生透明桌面悬浮窗，不再打开网页。
- 默认置顶，可在右键菜单里切换。
- 支持待机、挥手、跳跃、失败、等待、处理、复核、向左走、向右走。
- 使用当前补帧资源：12-24 帧动作序列。

文件：
- YakmoDesktopPet.exe：单文件桌宠程序，内置全部动作资源。
- pet-resources/：原始模型 JSON 和动作 PNG，便于二次修改。
- checksums-sha256.txt：文件校验。

说明：
这是基于当前牦牦 Live2D-like 资源制作的桌宠 exe，不是 Cubism .moc3 桌宠。
